# FinCap - Expense Tracker

FinCap là ứng dụng quản lý chi tiêu cá nhân & nhóm, hỗ trợ theo dõi, phân tích và tối ưu hóa tài chính cá nhân.

## Cài đặt & chạy dự án

### Yêu cầu
- Node.js >= 18
- Yarn hoặc npm

### Cài đặt

```bash
# Cài dependencies
npm install
# hoặc
yarn install
```

### Chạy ứng dụng

```bash
npm run dev
# hoặc
yarn dev
```
